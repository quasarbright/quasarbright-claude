# WRITING.md moved

As of plugin 0.14.0 (2026-11-24), the lessons for writing live in Mike's live taste store, a private artifact
every session and project shares. Since 0.16.1 they're split three ways: UI wording such as labels
and buttons is domain `ui` (topic Wording), jokes and character lines are domain `humor`, and
longer writing (about modals, descriptions, READMEs, blog posts) is domain `writing`. Read and add to them as the
`persona` skill says (`skills/persona/SKILL.md`). Nothing new goes in this file.
